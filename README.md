# Najwa Kamila Salma — Engineering Portfolio

Website portofolio personal berbasis HTML, CSS, dan JavaScript sederhana.

## Menjalankan secara lokal
Buka `index.html` di browser. Seluruh gambar lokal berada di folder `assets/`.

## Deploy ke GitHub Pages
1. Buat repository GitHub baru, misalnya `najwa-portfolio`.
2. Upload `index.html`, folder `assets/`, dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses deployment. GitHub akan menampilkan URL website di bagian Pages.

## Catatan sebelum dipublikasikan
- Periksa kembali seluruh informasi, nama kegiatan, dan sertifikat.
- Pastikan kamu nyaman menampilkan foto dokumentasi dan informasi kontak di website publik.
- Jika ingin mengganti foto profil, ganti `assets/najwa-portrait.jpg` dengan foto baru dan pertahankan nama file tersebut.
- Website menggunakan Google Fonts; jika tidak ada koneksi internet, browser akan menggunakan font fallback.
